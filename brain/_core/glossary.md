# 共用名詞（全專案唯一定義）

> 只放跨 Skill 共用的名詞；某個 Skill 專用的名詞放在該 Skill 的 `context.md`「名詞」。

| 名詞 | 定義 |
|---|---|
| OP | Operations，營運團隊 |
| AC | Account 相關業務（開戶、帳戶異動、IB、CPA…），團隊標籤 AO |
| DW | Deposit / Withdrawal 出入金業務 |
| Roster | 員工名冊；擁有者 team-structure |
| 正式姓名 | Roster 的 `OP Name`／`CRM OP Name`；全專案人名的標準寫法 |
| Lark Name | 員工在 Lark 的顯示名 |
| 人員標籤 | Roster 中的屬性欄（superior、Team、Office、Duty Time、Joining Date…）；可作為篩選條件 |
| Productivity Point（人效積分） | 1 point ≈ 2 分鐘人力成本；人效與 QC 共用的單位，分 AC／DW。各工作項目的分數待「人效積分總表」 |
| Item list | 工作項目目錄（未來）：每個工作項目的分類、AC／DW、積分；依賴 team-structure |
| 人效 | 工作量（完成量）與其人力成本（時間）；用來與排班、加班、進線量、QC 交叉分析 |
| Skill | 一個業務主題的知識庫 + 工具（OpBrain 格式） |
| 流程（flow） | Skill 內一條具名的步驟序列，例 productivity 的 pbi、fresh、chatgroup |
| 動作（ACT） | 一支步驟腳本 |
| 關卡（gate） | 檢查沒過就停止，結束碼 2 |
| 標準答案（baseline） | 回歸測試用的已確認輸出，`data/_baseline/` |
